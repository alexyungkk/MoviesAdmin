Movies Administration App
A movies review website's administration application
Administrator login the website and execute CRUD, create, read, update, and delete movies data.
There are several movies data will be stored in database, title, synopsis, genre, rating, runtime in hours and minutes, and launch date.
It displays a list which summaries all the movies in release date order.


Built with
IDE: Microsoft Visual Studio 2026
Language: C#
Framework: ASP.NET Core MVC
Database: Entity Framework and SQL Server
